## Layout

- `index.html` — entry page (intro text, Continue button, canvas dither art).
- `gallery.html` — the gallery itself; reads the generated `projects.json`.
- `index-of.html` — keyboard-navigable file tree; reads the generated `tree.json`.
- `assets/site.css` — shared palette and shell for every page.
  Base palette `#F6F4F1` / `#222526` with `#9C90FC` as the accent.
- `assets/theme.js` — shared light/dark toggle. Load it with a plain
  `<script src>` in `<head>` (no `defer`) so the stored theme is applied
  before the first paint.
- `projects.json` and `tree.json` are generated by `scripts/build-gallery.mjs`
  and `scripts/build-tree.mjs`, and by CI on every push to `main`. Do not
  hand-edit either; edit each project's `project.json` instead.
- `tree.json` records no file sizes on purpose: it lists itself, so storing its
  own size would change the file on every run and the index would never settle.

New project pages should link `assets/site.css` and `assets/theme.js`, and
include the `.theme-toggle` button so the toggle appears on every page.
